# Documentation Structure

This folder contains shared project documentation. Phase-specific backend and frontend documentation is located in `backend/docs/` and `frontend/docs/` respectively.

## Folder Organization

```
docs/
├── OFFICE_SEAT_ALLOCATION_PRD.md              # Product requirements
├── PHASE_1_IMPLEMENTATION_PLAN.md             # Phase 1 overview
├── PHASE_2_IMPLEMENTATION_PLAN.md             # Phase 2 overview
├── ARCHITECTURE_DECISION_RECORDS.md           # Design decisions
├── TECHNICAL_IMPLEMENTATION_DOCUMENT.md       # Detailed tech specs
├── TECHNICAL_IMPLEMENTATION_DOCUMENT_SIMPLIFIED.md  # Tech overview
├── DEPLOYMENT_GUIDE.md                        # Deployment procedures
├── API_DOCUMENTATION.md                       # API reference
├── DEVELOPMENT_GUIDELINES.md                  # Coding standards
├── TESTING_STRATEGY.md                        # Testing approach
├── DOCUMENTATION_INDEX.md                     # Complete index
└── README.md                                  # This file

backend/docs/
├── BACKEND_PHASE_1_DETAILED_PLAN.md           # Backend Phase 1 specs
└── BACKEND_PHASE_2_DETAILED_PLAN.md           # Backend Phase 2 specs

frontend/docs/
├── FRONTEND_PHASE_1_DETAILED_PLAN.md          # Frontend Phase 1 specs
└── FRONTEND_PHASE_2_DETAILED_PLAN.md          # Frontend Phase 2 specs
```
